Fetch `/robots.txt`, classify each of 16 known AI bots as `allowed | blocked | unmentioned`, compute a 0–100 score.

**Rate limit:** 10 req/min per IP.

**Request body:**
```json
{ "domain": "example.com" }
```

**Success (200):**
```json
{
  "bots": {
    "GPTBot": "blocked",
    "ClaudeBot": "allowed",
    "PerplexityBot": "unmentioned"
  },
  "score": 62,
  "hasRobotsTxt": true,
  "hasWildcardAllowAll": false,
  "warnings": ["No training-only bots (CCBot, Bytespider, Google-Extended) are explicitly blocked."]
}
```
Tracked bots: `GPTBot, ChatGPT-User, OAI-SearchBot, ClaudeBot, Claude-Web, anthropic-ai, PerplexityBot, Perplexity-User, Google-Extended, Googlebot, CCBot, Bytespider, Applebot-Extended, Amazonbot, FacebookBot, Meta-ExternalAgent`.

**Errors:**
- `400 { "error": "Invalid domain" }`
- `429 { "error": "Rate limit exceeded. Try again in a minute." }`
- `502 { "error": "Could not fetch robots.txt" }`
