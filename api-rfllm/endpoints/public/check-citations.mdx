---
title: 'Check Citations'
openapi: 'POST /public/check-citations'
---

Ask Gemini 2.0 Flash to list the top 5 brands for each of up to 3 topics; report whether the target domain appears in each answer.

**Auth:** tool token, purpose `check-citations`.

**Request body:**
```json
{ "domain": "example.com", "topics": ["project management saas", "team collaboration"] }
```
1 ≤ `topics.length` ≤ 3.

**Success (200):**
```json
{
  "domain": "example.com",
  "results": {
    "project management saas": { "mentioned": true, "response": "The top 5 are..." }
  },
  "score": 50
}
```
`score = round(mentionCount / topics.length * 100)`. `response` is truncated to 500 chars.

**Errors:**
- `400 { "error": "Invalid domain" }`
- `400 { "error": "Provide 1-3 topics" }`
- `403 { "error": "Forbidden", "reason": <token-reason> }`
- `429 { "error": "Rate limit exceeded. Try again in a minute." }`
- `429 { "error": "...", "reason": "cap_hit" | "tool_disabled" }`

**Side effects:** up to 3 Gemini calls, one `free_scan_leads` insert.
